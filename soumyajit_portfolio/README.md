# Soumyajit Mukherjee — Sales Leadership Portfolio

Responsive Next.js portfolio designed for GitHub + Vercel deployment.

## Run locally
1. Install Node.js 20+.
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

## Deploy
Import this repository into Vercel. The default Next.js build settings are sufficient.

## Included assets
- `public/assets/sm-logo.png` — approved personal monogram
- `public/assets/Soumyajit-Mukherjee-Resume.pdf` — resume download linked in the site

## Notes on content
Revenue figures were entered from user-provided updates. Vedantu ₹40–50 lakh is shown without a period because none was specified. Scaler ₹30–40 lakh/month individual contribution and ₹75–80 lakh/month team revenue after promotion are shown as user-reported updates. Case study narratives use resume and conversation context; avoid implying that illustrative framing is a verified incident.

Company logos are fetched via Google favicon endpoint using company domains; they require an internet connection. For a production-quality final, replace with verified official logo SVG/PNG assets if any favicon appears incomplete or changes.

The hero portrait is a placeholder pending a suitable personal photo. Replace it with a square photo in the hero container.
